# uuid

An unofficial C# conversion of the Go module [`github.com/google/uuid`](https://github.com/google/uuid), produced by [go2cs](https://github.com/ritchiecarroll/go2cs) as a proof of its third-party conversion path.

This repository is not affiliated with or endorsed by Google, the authors of `github.com/google/uuid`, or the Go project. Go users should use the upstream module.

## NuGet

The conversion will publish as the NuGet package `nugetgo.github.com.google.uuid`, version `1.6.0`. A rebuild of the same Go version adds a fourth, revision part: `1.6.0.N`, where N counts up from 1. Nothing is published yet.
